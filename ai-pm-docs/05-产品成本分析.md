# 05 · 产品成本与定价分析（AI PM 视角）

> **文档定位**：用真实数据回答"这个 AI 产品能不能赚钱"——每一个功能的真实边际成本是多少，定价是否合理，毛利是否健康。
>
> **重要澄清**：本产品的"语音面试"和"定向备考（RAG）"是**完全独立的两条产品线**——语音面试不用 RAG，定向备考是文字面试。问答助手是纯 RAG 文字聊天，作为赠送轮次。

## 二、真实产品结构（4 个功能）

```
产品功能地图
│
├─ 【功能 1】简历分析                  ← 免费引流，边际成本 ¥0.02
│
├─ 【功能 2】语音模拟面试 ★ 核心       ← 变现核心，边际成本 ¥2.07
│   （真·语音对话，ASR + TTS + LLM）
│
├─ 【功能 3】定向备考（知识库面试）     ← 差异化，边际成本 ¥0.28
│   （上传面经 → RAG 生成题库 → 文字面试）
│
├─ 【功能 4】问答助手                  ← 赠送轮次，边际成本 ¥0.013/轮
│   （纯文字 RAG 聊天）
│
└─ 【功能 5】面试日程管理              ← MVP 不做，已隐藏
```

### 关键架构事实

| 事实 | 含义 |
|---|---|
| **语音面试不用 RAG** | 语音面试的 prompt 只来自 Skill 预设 + 简历 |
| **定向备考是文字面试** | 上传面经 → 生成题库 → 打字作答 |
| **问答助手是纯 RAG 聊天** | 不是面试，是辅助问答 |

## 六、产品包装建议

### 不要这样说

> "9.9 元 = 1 次语音面试 + 1 次文字面试 + 10 轮问答"

### 要这样说

> **9.9 元 = 完整面试备战方案**
> 
> - 🎤 **语音模拟面试**：开口练，模拟真实面试压力
> - 📚 **定制化备战**：上传目标公司面经，针对性练习
> - 💬 **智能问答**：10 轮 AI 问答，随时解惑
> - 📄 **简历分析**：AI 评分 + 改进建议
> 
> **双管齐下，面试成功率翻倍**

## 七、后续优化方向

| 方向 | 预期收益 |
|---|---|
| 压缩语音时长（客户端 VAD + 回声防护） | ASR/TTS 成本下降 20-30% |
| 换更便宜的 TTS 模型（如 cosyvoice 系列） | TTS 成本下降 30-50% |
| 设置单次面试时长上限 60 分钟 | 避免极端情况侵蚀毛利 |
| JD 解析功能完善（注入 prompt） | 让"定制化"真正生效 |
